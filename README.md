# html-css-toboolist

> **Breve descrizione:**
> Realizzare una web page sfruttando l'immagine in allegato, utilizzando HTML e CSS, per ottenere un layout il più fedele possibile all'originale.

---

## 📚 Tecnologie utilizzate

**Linguaggi e tecnologie:**

- **HTML:** Linguaggio di markup per strutturare il contenuto.
- **CSS:** Linguaggio per definire lo stile e l'aspetto dei contenuti.

---

## 🎯 Obiettivi del progetto

📌 **Scopo principale:** Creare una web page che simuli una todolist, ispirandosi all'immagine in allegato per mantenere il layout il più fedele possibile all'originale, utilizzando HTML e CSS.

📌 **Competenze acquisite:**

- 🔹 Utilizzo dei tag base di HTML.
- 🔹 Applicazione delle proprietà CSS per gestire sizing, spacing e colori degli elementi.

---

## Installazione e Avvio

Segui questi passaggi per installare e avviare il progetto:

```bash
# Clona il repository
git clone https://github.com/JoseManuel-Feliz/html-css-toboolist.git

# Entra nella cartella del progetto
cd html-css-toboolist

```

## 📝 Issue e Bug

Se trovi un **bug** o hai un'idea per migliorare il progetto, apri un'**issue** nella sezione ["Issues"](https://github.com/JoseManuel-Feliz/html-css-toboolist/issues).

**Come segnalare un bug:**

1. Vai alla sezione **Issues** del repository.
2. Clicca su **New Issue**.
3. Descrivi il problema in modo dettagliato.
4. Se possibile, allega screenshot o log di errore.

**Come proporre una nuova funzionalità:**

1. Vai alla sezione **Issues**.
2. Clicca su **New Issue**.
3. Seleziona **Feature Request**. _(Se non trovi questa opzione, crea comunque la issue e aggiungi manualmente l'etichetta `feature request` oppure indica nella descrizione che si tratta di una proposta di funzionalità.)_
4. Spiega il miglioramento proposto.
